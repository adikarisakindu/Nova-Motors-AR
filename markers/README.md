# Hiro marker

Use the official marker here:

https://raw.githubusercontent.com/AR-js-org/AR.js/master/data/images/hiro.png

Display the image on a second screen or print it about 8–10 cm wide with its complete black border and surrounding white margin. Show the full image to the camera in good, even light. The assignment and lecture use `preset="hiro"`, so the marker must be the official Hiro pattern rather than a different square image.

For reliable testing, avoid opening the marker on the same screen whose camera is in use; use a second device or printed paper.
